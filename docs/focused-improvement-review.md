# Focused Improvement Review

The review prioritizes friction that affects the first task, task recovery, and notification readiness. The existing interface already communicates safety boundaries well; the selected work improves discoverability and control without expanding any external-action capability.

| Opportunity | Selected Improvement | User Benefit |
| --- | --- | --- |
| The Chat tab opens with a blank composer and a general welcome message. | Add editable starter prompts that prefill the composer rather than send requests automatically. | New users can begin quickly while retaining review and control of every request. |
| Activity shows all task states in one long chronological list. | Add concise filters for all, active, attention-required, and completed records. | Users can find blocked, failed, waiting, and completed work without losing the full audit trail. |
| The notification and device-registration controls are technically safe but visually look equally actionable in every state. | Improve disabled affordances and add contextual status labels. | Users understand when a setting must be enabled before a local test or device registration can proceed. |
