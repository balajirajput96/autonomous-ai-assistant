# Topic Taxonomy and Source Framework

The mission uses a constrained topic registry rather than a list of interchangeable “brain facts.” Each reel is assigned exactly one primary domain, one subdomain, a claim type, a source-quality tier, and a distinct audience question. All empirical reels must be researched individually before scripting.

## Minimum source tiers

| Tier | Permitted use |
| --- | --- |
| A | systematic reviews, meta-analyses, clinical guidelines, established datasets; preferred for central claims. |
| B | original peer-reviewed research, ideally with public abstract/full text and clear methods. |
| C | university or research-institute explanation used only to clarify, never to replace the underlying central evidence. |
| D | books, recognised expert interviews/podcasts, or philosophical primary texts; labelled as interpretation, tradition or philosophy rather than experimental proof. |
