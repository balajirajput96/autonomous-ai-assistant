# Reel 0023 — Hindi Voiceover

एक reward आज exciting और कल normal क्यों लगता है? Reward prediction error एक learning model है। इसमें सिर्फ reward नहीं, आपकी उम्मीद और असली outcome का फर्क मायने रखता है।

Quiz में छोटा reward expected था, लेकिन बेहतर मिला: model इसे positive prediction error कहता है। Result बिल्कुल expected हो, तो नया surprise कम है। उम्मीद से कम outcome को negative prediction error term कहा जाता है।

Controlled reward-learning tasks में ऐसे mismatch signals को learning models और dopamine-related activity के साथ जोड़ा गया है। यह अगली बार की expectation update करने में मदद कर सकता है।

पर ध्यान: dopamine मतलब pleasure नहीं। Reward prediction error खुशी का meter या किसी person का diagnosis नहीं है। Human imaging में कुछ patterns models के consistent मिले हैं, लेकिन exact algorithm अभी भी open question है।

Takeaway: surprise से learning update हो सकती है; पर एक feeling, एक choice, या पूरी कहानी को सिर्फ reward prediction error नहीं कहा जा सकता।
